# 管理器退出与紧急结束

托盘“退出管理器”原来在切换期间直接拒绝，因此用户看到进程仍在。现在该操作会请求取消当前切换，等待切换服务完成回滚，然后自动退出管理器。

窗口新增“紧急结束管理器”按钮：空闲时正常退出；切换或恢复中经二次确认后立即结束管理器进程。该方式仅供恢复本身也卡住时使用，可能需要手动检查 VPN 和用户代理变量。此按钮不会结束 Clash、TiziGo 或 Codex。

验证：.NET 构建与 43 项离线检查通过；1.1.5 安装结果 `networkChanged=false`；安装时旧管理器正常退出，新进程启动。随后向新管理器发送同一个退出事件，原进程结束并记录“程序退出”。不在当前 Codex 会话里执行真实 VPN 切换，因此“切换中请求退出”和“紧急结束”的交互仍待真实切换时验收。
